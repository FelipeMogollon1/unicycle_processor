# unicycle_processor

A single-cycle processor simulator developed in Python, designed to demonstrate the internal workings of a MIPS-style architecture. The project implements key CPU components such as the ALU, register bank, instruction memory, data memory, and control unit, allowing instructions to be executed cycle by cycle and the data path flow to be visualized.

---

## 📚 Project Overview

This project simulates the behavior of a **single-cycle processor architecture**, inspired by the MIPS processor model commonly studied in computer architecture courses.

The simulator aims to provide an educational and visual understanding of how instructions move through the processor datapath and how core hardware components interact during execution.

---

## 🚀 Features

- Arithmetic Logic Unit (ALU)
- Register File / Register Bank
- Instruction Memory
- Data Memory
- Control Unit
- Program Counter (PC)
- Step-by-step instruction execution
- Datapath visualization
- Modular architecture in Python
- Educational CPU simulation
